MoE Token Dispatch

Measured token packing and weighted output combination on one GPU. CUDA kernels count expert assignments, calculate offsets, pack token rows, and combine outputs with FP32 accumulation.

NVIDIA A100-SXM4-40GB36 edge-case checks passed12 benchmark configurationsMoE feedforward block verified

Measurement scope

Dispatch/combine transport only, FP16 inputs with FP32 weighted accumulation. The reference uses GPU sorting, indexing, multiplication and reduction; CUDA uses atomic slot assignment, a tiny expert scan, row packing and fused weighted gather. The separate MoE block checks forward correctness; no model/block speedup is claimed. Workspace bytes are explicit persistent buffers, not peak CUDA allocator usage. No comparison to NVIDIA/other production MoE libraries has been run.

CUDA-event GPU stream elapsed time; per-call samples after warmup. Both paths reuse workspaces; count reset is timed. Compilation, input generation, router, validation, and expert computation are excluded. Small cases include launch gaps.
