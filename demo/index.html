Validation and reproduction

Recorded A100 run: 81 CPU tests, 39 GPU tests, and 36 standalone transport checks passed. All 22 measured source hashes match the release. Maximum quick-suite absolute error: 0.0078125; relative L2 error: 0.0002143. Profiler trace contains 36 GPU kernel events.
